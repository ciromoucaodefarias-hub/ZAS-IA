# ZAS-IA

Este repositório contém o projeto ZAS IA — Criador Inteligente de Sites. Vou adicionar arquivos iniciais (cliente e servidor proxy) em uma branch separada depois de criar este commit inicial.

Conteúdo do README.md:

ZAS IA
======

Criador Inteligente de Sites (proxy seguro para OpenAI)

Instruções rápidas:

1. Copie este repositório localmente.
2. Crie um arquivo .env com a variável OPENAI_API_KEY.
3. Instale dependências: npm install
4. Rode em desenvolvimento: npm run dev

Observações:
- A chave da OpenAI NUNCA deve ficar exposta no frontend (navegador).
- A branch `add/server-proxy` conterá o servidor proxy (Express) e o cliente melhorado para geração de sites.
